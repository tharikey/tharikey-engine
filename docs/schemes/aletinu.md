# Áletinu

`aletinu` · **text** · reversible (lossy) · **experimental.**

"Áletinu" (*New Dhivehi Latin*) is a strict **one-sound-one-letter** romanization — proposed by
[*thatmaldivesblog*](https://thatmaldivesblog.wordpress.com/2016/06/07/new-dhivehi-latin/) (2016),
re-encoded here with attribution. It leans on diacritic letters so every Thaana consonant and vowel has
a single, unambiguous spelling.

!!! warning "Preview"
    Treat Áletinu as a preview. Gemination works; **prenasalisation is not built**, `æ → ައި` doesn't
    round-trip, and a few consonants with alternate spellings collapse to one form on reverse.

## Consonants

Plain letters where they fit (`h ހ`, `n ނ`, `r ރ`, `b ބ`, `k ކ`, `v ވ`, `m މ`, `f ފ`, `l ލ`, `g ގ`,
`s ސ`, `z ޒ`, `t ޓ`, `y ޔ`, `p ޕ`, `j ޖ`, `c ޗ`), and diacritic letters for the rest:

| | | | | | |
|--|--|--|--|--|--|
| `x` ށ | `ð` ދ | `þ` ތ | `ł` ޅ | `ñ` ޏ | `d` ޑ |

Arabic-loan (*thiki*) letters use further diacritics — `ħ ޙ`, `ĥ ޚ`, `ġ ޣ`, `ĝ ޤ`, `ŝ ޝ`, `ş ޞ`,
`ś ޟ`, `ŧ ޡ`, `ţ ޠ`, `š ޘ`, `ď ޛ`, `ŕ ޜ`, `w ޥ`, `'` ޢ — several with alternate forms (`ž ż ť ø ů`).

## Vowels

| short | long |
|--|--|
| `a` ަ | `á` / `ā` ާ |
| `i` ި | `í` / `ī` ީ |
| `u` ު | `ú` / `ū` ޫ |
| `e` ެ | `é` / `ē` ޭ |
| `o` ޮ | `ó` / `ō` ޯ |

Plus the special diphthong `æ` → ައި (e.g. `Fæ → ފައި`).

## Glottal

`q` is the glottal stop → އް (`Boq → ބޮއް`). On reverse, a word-final `އް` maps back to `q`.
